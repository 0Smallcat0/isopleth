# Chart Studio QA checklist (T13)

One row per item of T13 in `.kiro/specs/chart-studio/tasks.md`. The two "Examples" bullets of T13 are one row here, and the example count is the seven in `src/core/examples.js`: `ohms-law`, `bmi`, `body-surface-area`, `hypotenuse`, `reynolds`, `axial-stress`, `weighted-sum`.

How to read the evidence column:

- A test file and test name is run by `npm test` and fails the build if it breaks.
- `shoot.py` is `scripts/shoot.py` (headless Chrome, Python Playwright; serve the repo root, then `python scripts/shoot.py http://127.0.0.1:4719/ work/shots`). It exits 1 only for a console error, a label overlap (`all_examples_overlap`), a scale off the sheet (`bmi_scales_on_sheet`, `typed_scales_on_sheet`) or a failed responsive check (`responsive.ok`). Those keys are **asserted**. Every other key it prints is **recorded**: it lands in the JSON for you to read and nothing compares it with an expected value.
- "not automated - check by hand" means no script touches it.
